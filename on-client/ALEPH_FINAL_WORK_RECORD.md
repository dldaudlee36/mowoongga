## 3. 고른 핵심 기능 3개

### 핵심 기능 1
- 기능 이름: 내 PC 자원 실측치 (CPU · 메모리 · 디스크)
- 제공된 부분: 없음 (student/extension.mjs 확장 영역에 구현)
- 내가 직접 개선한 부분: Node.js 시스템 API 및 브라우저 하드웨어 텔레메트리 기반 CPU 사용률(%), 메모리 사용량(GB/MB), 디스크 잔여 공간 실측치 및 잰 시각·단위 표시 (Cyber Sentinel 관제 대시보드 4대 카드 UI)
- 실제 확인 결과: 재현됨 (16 코어, 15.8 GB 메모리, C: 드라이브 296.5 GB 여유 및 잰 시각 실시간 표기 확인)
- 잘못된 입력이나 연결 실패 때의 동작: 0이나 가짜 값 대신 「확인 불가 (브라우저 보안 권한 제한)」 표시
- 근거(개인정보를 지운 화면, 실행 기록, 상대 경로): student/extension.mjs (renderStatus), http://127.0.0.1:5189 관제 대시보드 카드 화면

### 핵심 기능 2
- 기능 이름: 로컬 네트워크 및 방화벽 상태 조회 (안전 읽기 전용)
- 제공된 부분: 없음 (student/extension.mjs 확장 영역에 구현)
- 내가 직접 개선한 부분: 네트워크 연결 상태(온라인/이더넷/루프백), Windows 방화벽 활성화 여부(설정 변경 없이 읽기 전용), 최근 시스템 이벤트 경고 3건 요약(침해 판정 결과 아님을 명시), SDP 서버 연결 상태(SDP 미연결)를 PC 로컬 조회와 명확히 분리 표기
- 실제 확인 결과: 재현됨 (온라인 상태, 방화벽 켜짐, 경고 3건·오류 0건, SDP 미연결 분리 확인)

### 핵심 기능 3
- 기능 이름: 사용자 편의 조작 UI (「다시 조회」 및 친절한 오류 화면)
- 제공된 부분: 상단 공통 새로고침
- 내가 직접 개선한 부분: 학생 구현 영역 전용 「다시 조회」 버튼, 300ms 로딩 대기 상태, 조회 실패 시 실패 항목·발생 원인·권장 조치(다음 행동)를 명확히 안내하는 친절한 오류 화면(Fallback) 및 원클릭 복구 버튼 구현
- 실제 확인 결과: 재현됨 (「⟳ 다시 조회」 클릭 시 실측 시각 실시간 갱신 및 토스트 알림, 「⚠ 오류 화면 시험」 클릭 시 비침해·확인불가 Fallback 카드 전환 및 「⟳ 복구 및 다시 조회」 정상 복원 확인)
- 잘못된 입력이나 연결 실패 때의 동작: 실패 항목, 구체적 원인, 다음 취할 권장 조치 3단계 표시
- 근거(개인정보를 지운 화면, 실행 기록, 상대 경로): student/extension.mjs (renderStatus), http://127.0.0.1:5189 보호 현황 상단 컨트롤 바

## 6. 처음 사용한 사람이 막힌 곳
- 다른 사람의 첫 사용 관찰 여부: 실시 (동료 학생 및 비전공자 대상 화면 조작 관찰 진행)
- 막힌 위치:
  1. 화면을 처음 열었을 때 `ALEPH SDP 미연결` 및 `경고 3건` 문구를 보고 내 PC가 해킹당했거나 에이전트가 고장 난 것으로 오인하여 불안해함 (상황 인식 부족).
  2. `다시 조회` 버튼을 눌렀을 때 실제로 센서에서 다시 읽어왔는지 변화를 즉각 체감하지 못해 버튼을 연타함.
  3. 키보드로만 화면을 탐색할 때 어느 카드를 보고 있는지 포커스 인지가 어려웠음.
- 내가 보완한 것:
  1. **상단 종합 안심 요약 배너 (Health Ribbon)**: 대시보드 최상단에 `🛡️ 종합 판정: 내 PC 로컬 보안 정상 (보호 활성화 · 침해 위협 없음)` 배너를 배치하여 1초 만에 전체 안전 상태를 인지하도록 개선.
  2. **기술 용어 인라인 안내 툴팁(ⓘ)**: SDP 미연결(운영진 서버 대기이며 로컬 보호 정상), 이벤트 경고(단순 시스템 경고이며 침해 사고 아님), 방화벽(읽기 전용) 등 용어별 마우스 호버/스크린리더 설명 추가.
  3. **다시 조회 실시간 스피너 및 갱신 완료 토스트**: 클릭 시 `⟳ 조회 중...` 회전 스피너 애니메이션과 함께 `aria-busy` 처리, 280ms 후 실측 시각 갱신 및 녹색 완료 토스트 제공.
  4. **단축키(Alt + R) 및 키보드 접근성(tabindex)**: 마우스 없이도 `Alt + R`로 즉시 실측치를 새로고침할 수 있게 하고, 모든 관제 카드에 키보드 포커스 및 포커스 링 지원.
- 다른 사람이 보완 뒤 다시 따라 해 본 결과: 상단 요약 배너를 보고 첫눈에 "내 PC는 안전하구나" 하고 안심했으며, SDP 미연결 툴팁을 읽고 정상 대기 상태임을 바로 이해함. 다시 조회 클릭 시 회전 스피너와 완료 안내가 떠서 안심하고 조작을 마침.
- 내가 직접 보완 뒤 다시 실행한 결과: 재현됨 (`http://127.0.0.1:5189` 보호 현황에서 상단 안심 배너, 용어 툴팁 4종, `Alt + R` 새로고침 스피너 및 오류 복구 인터랙션 정상 확인 완료).
