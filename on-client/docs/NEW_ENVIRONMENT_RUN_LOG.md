# 모웅가(mowoongga) 새 환경 실행 기록

## 확인 범위 및 기록 기준

- **기록 버전:** `v0.9-verification` — 검증 중
- **확인 시각:** 미확인
- **이번 확인 범위:** 기존 새 환경 실행 기록, 교육과정 단계표, 재현 기록 파일을 읽었습니다. 앱이나 서버를 실행하거나 브라우저를 확인하지 않았고, 테스트도 실행하지 않았습니다.
- **새 환경에서 직접 확인해 전달된 결과:** 현재 대화에는 새 환경의 단계별 실행 결과와 확인 시각이 전달되지 않았습니다. 따라서 아래 표의 확인 내용·결과·시각은 모두 **미확인**입니다.
- 이전 대화에서 알려 주신 13~15단계 공식 통과 및 17단계 심사 피드백은 새 환경에서의 누적 재현 결과가 아니므로 표의 새 환경 결과로 옮기지 않았습니다. 이전 재현 기록 문서에 적힌 결과도 이번에 직접 재현하거나 확인한 사실로 취급하지 않았습니다.
- `demo` 결과가 직접 보고되더라도 결과를 **재현됨**으로 적지 않고, 비고에 **예제 자료**라고 표시합니다.
- **`v1.0`은 표시하지 않습니다.** 19단계의 실제 실행 연결과 22단계의 같은 최종 소스 누적 재현·공식 접수 연결이 모두 완료되고 수용됐다는 결과를 직접 확인하기 전까지 검증 중 버전을 유지합니다.

## 기다림(UNV)

- **13~21단계 누적 재현:** 동일한 최종 소스를 새 환경에서 실행하고 각 단계 기능을 직접 확인한 결과.
- **17단계 실제 AI 연결과 오류 전달:** 실제 AI 호출 경로·권한·응답, 네트워크 오류 원인이 화면까지 구분되어 전달되는지에 대한 새 환경 확인.
- **18단계 실제 사건 설명:** 선택 사건에 대한 실제 AI 응답 및 근거 검증이 새 환경에서 동작하는지.
- **19단계 실제 실행 연결:** 원천 실행기로의 연결, 사람 확인 절차, 서버 처리 결과와 효과 관측. 이 항목은 `v1.0` 판단의 필수 조건입니다.
- **20단계 실제 취약점 조회:** 새 환경에서의 lock 파일 기반 조회와 갱신 결과.
- **21단계 안내 재현:** 문서의 설치·실행 안내를 새 환경에서 따라 확인한 결과.
- **22단계 최종 누적 재현 및 공식 접수:** 13~21단계의 같은 최종 소스를 새 환경에서 누적 재현하고 공식 접수·수용된 결과. 이 항목과 19단계 실제 실행 연결이 모두 완료·수용되기 전에는 `v1.0`으로 올리지 않습니다.

직접 확인 결과를 전달받으면 해당하는 기능·결과·확인 시각만 기록하고, 말해 주지 않은 항목은 **미확인**으로 둡니다. `demo`는 비고에 **예제 자료**라고 표시하며 재현됨으로 기록하지 않습니다. 비밀번호, 토큰, 키 등 비밀 값은 기록하지 않습니다.
