## 2. 새 환경(클린 환경) 사양 및 설치·실행 절차

- **운영체제:** Windows 11 (64-bit), PowerShell 5.1
- **Node.js 버전:** `v24.20.0` (공식 검수 기준 `24.19.0`, 실행 도구 및 가이드 지원 범위 `22~24` 호환)
- **새 환경 작업 디렉터리:** `$env:TEMP\mowoongga-clean\on-client` (새 빈 디렉터리)
- **설치 및 실행 절차 (이동식 상대 경로 기준):**
  1. 새 빈 폴더 생성 및 이동:
     ```powershell
     mkdir $env:TEMP\mowoongga-clean
     cd $env:TEMP\mowoongga-clean
     ```
  2. 원격 저장소 복제:
     ```powershell
     git clone https://github.com/dldaudlee36/Fightvac.git .
     ```
  3. 앱 폴더로 이동:
     ```powershell
     cd on-client
     ```
  4. 학생 코드 문법 검사:
     ```powershell
     npm run check
     # 결과: node --check student/extension.mjs 정상 종료 (문법 오류 0건)
     ```
  5. 데모 서버 실행 및 포트 확인:
     ```powershell
     npm run demo
     # 결과: 포트 5189 바인딩 및 http://127.0.0.1:5189 HTTP 200 OK 응답 확인
     ```
  6. 프로세스 정상 종료 (`Ctrl + C`)

## 4. 기다림(UNV)

- **13~15단계 원천 엔진 실연결:** 실제 운영 SDP 호스트와의 통신을 통해 실제 사용자·기기·세션 및 XDR 경보를 수신하는 동작은 대기(UNV) 상태입니다.
- **17단계 실제 AI 연결과 오류 전달:** 실제 CLCO AI 게이트웨이 라이브 호출 권한 발급 및 네트워크 오류의 세부 전달은 운영 대기(UNV) 상태입니다.
- **18단계 실제 사건 설명:** 선택 사건에 대한 실제 AI 실시간 응답 및 원천 서명 검증은 운영 대기(UNV) 상태입니다.
- **19단계 실제 실행 연결:** 원천 조치 집행기로의 연결, 사람 확인 절차, 서버 처리 결과와 효과 관측(`effectApplied: true`). 이 항목은 `v1.0` 판단의 필수 조건입니다.
- **22단계 최종 누적 재현 및 공식 접수:** 13~21단계의 같은 최종 소스를 새 환경에서 누적 재현하고 공식 접수·수용된 결과. 이 항목과 19단계 실제 실행 연결이 모두 완료·수용되기 전에는 `v1.0`으로 올리지 않습니다.
